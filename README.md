# tulover-neobank
A scalable data engineering pipeline to ingest data produced from sources of the neobank for downstream usecases!

## Business problem
Neobanks produce large volume of data from core banking systems like transactions, payment gateways, credit reports. The data are stored in different formats in different places, making unified analytics tough.
These data exist in the form of data silos making operational analytics difficult. Manual processing at this scale would be slow,complex and hard to scale.

## Solution
Build a metadata-driven framework to create a scalable pipeline which takes data from its sources to ready-to-query form.
Create interactive dashboards and Genie AI interface for business users to query data easily.
